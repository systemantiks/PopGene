# PopGene 0.0.1 — consolidated local build

26 October 2026. Local build notes; this is not a public release announcement or a claim of complete format/display parity.

## Included

- Linked sequence/map annotations, complex locations, CDS/six-frame translation, 27 active genetic codes, ORFs and selected-CDS flanks.
- Protein composition, mass, selected-residue/modification analysis and named Bjellqvist, EMBOSS and Grimsley 2009 (IPC Arg) charge models. Bjellqvist remains the default.
- Primer3 thermodynamics/design/editing, stable display for uncolored primers, a 1,089-enzyme catalogue, custom enzyme lists and physical digestion.
- PCR, ligation, overlap and Golden Gate workflows, annotation ancestry reconstruction, and documented GenBank/EMBL supplements for physical fragments and partial CDS save/reopen/rejoin.
- Pairwise/multiple/POA alignment; ABIF/SCF/ZTR/FASTQ traces, alternate calls and nullable quality display; native references, attachments, supported history and original-record inspection.
- SVG/PDF/PNG figures with bundled fonts, transactional recovery, external-file conflict protection and parented chooser paths.
- Circular native RNA with zero stickiness retains inactive terminal fields without inventing exposed ends or duplex geometry.

## Verification

The immutable source0017 baseline passed **443 workspace tests** (129 core, 143 desktop, 171 formats), formatting, strict all-target lint and debug linking on macOS ARM64 and Linux ARM64. Windows GNU workspace test compilation, strict lint and debug cross-linking passed. Windows runtime and MSVC were unavailable.

Focused GUI checks verified macOS crash recovery and actual GenBank/EMBL fragment save, close, reopen and rejoin. The exact saved native product displayed 15 bases, one blue phase-2 CDS and WNSS translation in the reference application. Explicit Grimsley selection displayed pI 7.603 and charge +1.179 at pH 7; changing pH invalidated the result until recalculation. Uncolored primers retained purple display after native Save/close/reopen while recorded-color swatches remained blank. Earlier Linux checks cover trace edits, save conflicts, recovery, primer/cloning workflows, figures and chooser callbacks.

The optimized macOS app passed Open cancellation/retry, multi-selection and subsequent opens after a temporary validation app had stalled. The original stall's cause is undetermined; no code fix is claimed. The final circular-RNA correction then passed **172 formats tests**, scoped strict lint, formatting and a byte-preserving reference-file probe. The full platform matrix was not repeated after this narrow patch.

## Retained limits

- Lossless native fuzzy, remote, mixed-strand and other unsupported location conversions remain unavailable. Unknown records and history actions are retained or disclosed rather than guessed; original settings are not silently applied.
- Standard readers may ignore or remove physical/ancestry comment supplements. Restoration requires valid retained evidence; ambiguous or edited mappings remain separate. The exact-product reference check does not prove reference-application reconstruction semantics.
- Stored alignments and RNA structures remain inspectable original metadata, not editable structure documents. Native line-style encoding and some active enzyme/visibility semantics remain unverified.
- Scientific calculations retain named assumptions: perfect-match primer thermodynamics, bounded design, exact cloning overlaps, curated restriction sensitivity, undefined cuts for 334 enzymes and approximate protein structure/property models. The protein mass-table difference is documented.
- Trace conversions may omit instrument/alternate-call metadata; unknown quality is not zero. Recovery restores one saved-to-recovered undo step, not the entire prior history.
- Windows runtime/MSVC and a complete repeat of every GUI path are not claimed. Public distribution/signing acceptance is separate from this local build.

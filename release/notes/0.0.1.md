# PopGene 0.0.1

First public preview of the native sequence workspace for Apple silicon Macs.

- Open and edit local DNA, RNA and protein documents.
- Explore linked sequence and map views, annotations, translations and restriction sites.
- Use **PopGene → Check for Updates…** to download, install and restart into future releases.

Requires macOS 12 or later and an Apple silicon Mac. Feature coverage and file-format support remain incomplete; see the repository README and file-format documentation before using this preview with important data.
